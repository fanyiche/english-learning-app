# Lingo Garden · 英语小花园

已新增 SwiftUI 原生 iPhone 工程：[`ios/LingoGarden.xcodeproj`](ios/LingoGarden.xcodeproj)。安装与真实验证状态见 [iOS 说明](ios/README.md)。原生工程尚未在 Xcode 编译或签名，当前没有可下载的安装包。

现有原生和网页界面均支持 **学生、律师、餐馆从业者、医护人员、商务办公** 五种学习模式；每种提供独立的词汇、语法与情景菜单，含 40 个职业词汇、15 个语法点和 70 道职业练习题。错题、已掌握词汇与课程进度按身份保留；XP、连续天数共用。

面向 iPhone 的原创英语学习应用首版，使用 Safari 打开，可添加到主屏幕（PWA）。也支持桌面和 iPad。采用原创花园视觉与原创课程内容。

## 运行

需要 Node.js 22 或更高版本，无 npm 运行依赖；Playwright 仅用于开发阶段的浏览器测试。

```sh
npm start
# 默认端口 3000；自定义：PORT=8080 npm start
npm test
```

浏览器回归（先在另一终端启动应用）：

```sh
npm ci
npx playwright install chromium
npm run test:browser
# 若已有 Chromium：CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
CHROMIUM_PATH=/usr/bin/chromium npm run test:careers
```

该回归覆盖手机与桌面布局、完整答题结算、错题复习、偏好及刷新持久化、离线重开，以及模拟模型响应后的课程保存与练习。模拟响应不代表真实 AI 推理已通过。

开发时使用 `npm run dev`。手机访问需要将服务部署至支持 Node.js 的 HTTPS 主机，或使用你自己的受信任 HTTPS 反向代理。iPhone 上的 localhost 指手机自身，不能直接访问开发电脑的 localhost。不要把开发服务直接暴露到不受信任网络；生产部署还需要访问控制、限流与监控。

## iPhone 使用

在 Safari 打开部署后的 HTTPS 地址 → 分享 → 添加到主屏幕。支持安全区域、独立窗口、底部导航和触控布局。首次成功打开并完成缓存后，内置课程、错题复习和本机进度可离线使用。缓存不包含 AI 请求；系统朗读需要设备上可用的英文语音。字体下载失败时会使用系统字体。

网页版本可以添加到主屏幕；`ios/` 目录另提供原生 SwiftUI 应用源码。原生版本尚未编译、签名或发布到 App Store，发行需要 macOS/Xcode、真机验证与开发者签名。

## 已实现

- 五种职业/身份模式，每种有词汇、语法和情景对话菜单。40 个词汇、15 个语法点，70 道职业练习。
- 另保留三节原创 A1 微课程：问候介绍、咖啡馆点单、日常表达；共 13 道选择、填空和听力题。
- 完整练习闭环：即时判分、解释、60% 完成门槛、每题 5 XP、结果页。
- 听说：系统英文朗读、浏览器语音识别跟读、文字输入替代。识别结果比对文字，不提供声学发音评分。Safari 支持、网络和麦克风授权会影响识别；浏览器语音识别可能由其在线服务处理。
- AI 英语老师：本机 Ollama 对话、语法讲解、情景模拟、课程生成。生成的结构化课程通过校验后保存到学习页，可答题和复习。
- 错题自动保存，复习答对后移除；推荐优先巩固错题，再推荐未完成课程。根据基础水平和错题调整 AI 提示。
- 每日 XP 目标、连续天数、4 个成就徽章和个人偏好。日期按设备本地日历计算。重复练习可继续获得 XP。
- 进度与 AI 课程保存在本机 localStorage；对话仅保存在页面内存。没有账号、跨设备同步、商业排行榜或付费系统。清理浏览器网站数据会清除记录。

## 本地 AI

当前不捆绑模型，不会用固定答案冒充模型输出。没有 Ollama 时，应用明确显示未连接，内置课程和标注的离线学习卡仍可使用。

在运行 Node 服务的同一台机器上，通过官方渠道安装 Ollama，再运行：

```sh
ollama serve
ollama pull qwen2.5:3b
# 另开终端，在本仓库运行
OLLAMA_MODEL=qwen2.5:3b npm start
```

如 Ollama 已作为服务运行，无需重复执行 `ollama serve`。建议至少 4–8 GB 可用内存，实际资源取决于模型与上下文。服务端仅调用 `127.0.0.1:11434`，无需 API 密钥。更换已安装的模型时设置 `OLLAMA_MODEL`，默认 `qwen2.5:3b`。在 AI 页面点击“重新检测”。

这里的“本地 AI”指 Node 服务器所在机器上的本地模型，不是 iPhone 设备端大模型。在手机上使用 AI，需要手机能访问此服务器。对话、学习基础和最近错题会发送到该机器。模型内容可能有误。课程生成依赖模型的 JSON 指令能力；校验失败会提示重试。尚未验证真实模型推理与 iPhone 真机语音权限行为。

## 验证

`npm test` 验证课程答案、结算门槛、XP 累计、日期/连续天数、错题推荐和 AI 课程结构校验。浏览器检查应覆盖完整答题、错题复习、刷新持久化、移动布局、PWA 缓存以及 AI 未连接状态。浏览器模拟不能替代 iPhone Safari 真机和麦克风测试。
